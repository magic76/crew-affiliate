# Private reporting core

No credentials needed for tests: node scripts/private-report-test.mjs. No live data is collected or published by GitHub CI. All report output must be written outside the checkout (exclusive mode 0600).

GSC: with a short-lived read-only OAuth access token in GSC_ACCESS_TOKEN and the property sc-domain:hicrewapps.com granted to the account, run node scripts/private-report.mjs gsc /private/gsc.json. The property is fixed, no Google write operations. Existing crew-seo public reports are Koolo-only; do not publish Affiliate GSC reports or upload artifacts to public repositories. Automated collection requires approved Google WIF mapping and a private destination.

Combined local report: node scripts/private-report.mjs report /private/report.json /private/input.json. Input is {period:{start,end}, metrics: [...] or null, gsc: collected report or null, commission: [...] or null}. Metrics rows match the existing D1 daily_metrics schema, exported via authenticated Cloudflare tools. GSC uses finalized dates in Pacific time; local metrics are Taipei time, so not exact event-level attribution. Commission is an INTERNAL normalized contract only: {day,currency:'TWD',status:'pending'|'confirmed'|'paid'|'reversed',orders,commission}; one aggregate per day/status. Map official export semantics only after reviewing documentation, never pass raw API responses, order IDs or PII. Keep missing data null. No report API calls to Coupang until parameter schema, attribution rules and currency/status semantics are confirmed. No public dashboard or report access endpoint is added.
