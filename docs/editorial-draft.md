# Editorial draft engine

No key required: `node scripts/editorial-draft-test.mjs`. Prepare one reviewed evidence JSON array outside the repository: [{ "id":"source-a", "label":"Original manufacturer documentation", "url":"https://...", "notes":"Paraphrased verified facts", "checkedOn":"YYYY-MM-DD" }]. Pick an unpublished candidate from data/topic-queue.json. `node scripts/editorial-draft.mjs brief TOPIC /private/evidence.json /private/brief.json` prepares a prompt. For manually supplied model JSON use `validate TOPIC EVIDENCE OUT RAW_DRAFT_JSON`. For optional live Gemini use `generate TOPIC EVIDENCE OUT` after configuring GEMINI_API_KEY and GEMINI_MODEL locally. The output parent must exist outside the repo; files are exclusive mode 0600. Never commit credentials or private evidence. Generation has no default model, retries, public artifacts, or automatic publishing. Source IDs and structural checks are not semantic fact-checking; editor must check every claim and calculations, set reviewedOn and open an ordinary reviewed guide PR separately. See https://ai.google.dev/gemini-api/docs/generate-content/structured-output.
